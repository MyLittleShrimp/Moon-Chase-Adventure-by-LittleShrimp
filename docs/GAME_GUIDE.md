# 游戏说明

你将扮演小拓，从水岸长街出发，寻找失踪的月亮。走近发光的任务标记后互动，解开城市设施与博物馆里的谜题。角色对话会提供下一步线索。

## 八项挑战

| 挑战 | 玩法 | 通关要求 |
| --- | --- | --- |
| 障碍贪吃蛇 | 方向键或屏幕方向按钮转弯 | 收集三个信标并到达出口 |
| 车阵华容道 | 选中车辆，沿车身方向移动 | 金色月光运输车抵达右侧出口 |
| 旋转管网 | 点击管件顺时针旋转，点击试水 | 连接左下入口和右上出口且不漏水 |
| 文博知识问答 | 在四个选项中选择答案 | 每轮五题，答对三题 |
| 能源推箱 | 推动能源箱；留意不能拉回的死角 | 把箱子推到目标格 |
| 联动电路 | 点击节点会切换相邻节点 | 点亮电路，启动核心 |
| 无人机配送 | 左右键或拖动飞行区域 | 穿过十二道挡板，保留至少一层护盾 |
| 反射镜光路 | 点击镜片改变反射方向 | 将光线引向右下方的月亮 |

## 探索与重玩

每处可探索场景都有一份隐藏食材。宝箱没有醒目的主线标记，靠近或点击后可以互动。已经收集的食材会放进行囊。完成故事并集齐八味食材，可触发玉兔的额外剧情。

「行旅」可以回到到访过的场景，并重新挑战已经完成的小游戏。最佳成绩保存在浏览器中。不同的剧情选择会通向不同的故事收束，不必在第一次游玩就找到全部内容。

## 体验设置

贪吃蛇默认舒缓航速，每格约 0.4 秒，障碍前有约 0.3 秒转向补救时间；挑战航速更快。方向输入可以缓冲两次转弯。答题关没有倒计时，也不要求连续答对。

点击 ♪ 可以切换声音，按 Esc 或暂停按钮暂停游戏。过场动画可以暂停、继续或跳过。视频缓冲期间显示首帧，不会只有黑屏。

## 存档

进度自动保存在当前设备、当前浏览器与当前网站地址下。切换浏览器、设备或网站地址不会自动迁移存档。清除网站数据会清除进度；重新开始会替换当前存档。
