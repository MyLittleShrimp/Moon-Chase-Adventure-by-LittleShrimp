# 手机兼容性修复记录

用户反馈：iPhone 17、iOS 26.6.1，主要是微信内置浏览器，部分 Safari 也卡在开场；智慧水务的弯管横竖长度不一致。网址：https://play.moonchase.fun/。

## 定位与修复

- 水管原来使用 `└ │ ─` 等字体字符。改为同一正方形坐标系内的 SVG 管线，四个接口均从格子中心延伸到对应边缘，长度、线宽和对齐不受系统字体影响。旋转、通水判定保持原规则；读屏标签直接描述接口方向。
- 原启动逻辑同时加载 16 张 PNG，合计 32.83 MiB，且全部成功之前一直禁用开始按钮；图片请求没有超时。现在开始按钮只等待游戏逻辑初始化，开场只预载团圆扉页和城市两张轻量图片，合计 380,722 字节，约 372 KiB。其余地图按需加载。
- `assets/web/` 是原图的网页副本。场景按实际画布尺寸生成，水务保留双画面；宝箱精灵图和投影局部图保留原尺寸，以免裁切坐标变化。原 PNG 保留作格式或请求失败的回退。生成脚本：`scripts/optimize_images.py`，需要 Pillow。
- 每种图片格式单次加载最多等待 8 秒，轻量图失败会尝试原 PNG。当前场景仍失败时显示重试/返回入口；等待期间阻止移动、不计时，防止在缺失地图上行走。重新载入与恢复网络均可重试，没有无限请求循环。
- 声音设置读取 `localStorage` 的动作移入异常保护范围。存储受限不会打断启动；无法保存进度时仍显示原来的存档提示。
- 独立启动脚本捕获模块加载或初始化错误，显示重试提示；10 秒仍未完成会提示网络较慢。重载链接即使脚本没有下载成功也能使用。

## 验证范围

48 项自动测试通过，包括两个航速的暂停、管网规则、按需图片加载、格式回退、超时重试、迟到回调隔离、存储受限，以及实际游戏入口在图片未完成/存储被禁用时进入动画、显示场景错误并重试恢复的集成测试。

本次使用 Windows 环境。线上旧版在桌面浏览器中可进入开场动画；这不能证明 iPhone/微信内核兼容。新版手机尺寸的浏览器检查因自动审批服务连接失败未完成，iPhone 17 的微信及 Safari 真机验收仍需复测。

本地故障注入只存在于开发服务器 `tests/preview-server.js` 的独立 4174 端口：`/?startup=normal`、`images`、`storage`、`module`。点击测试栏的「恢复网络」后可检查重试。`/puzzle-audit` 提供智慧水务直接检查入口。这些测试服务和注入代码不进入 `dist/`。
