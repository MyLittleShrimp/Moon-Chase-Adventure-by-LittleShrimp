## 接手顺序

1. 在根目录执行 `npm start`，确认 4188 打开的是本游戏。
2. 执行 `npm test`，确认全部通过。
3. 维护题库时同时更新 `quiz.js` 与 `QUIZ_SOURCES.md`。
4. 更换美术、音频或视频时保持引用一致，检查手机端与动画首帧。
5. 发布游戏网站时使用 `dist/`；上传源码仓库时保留整个本交付目录。
