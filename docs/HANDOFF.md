## 发布状态

本仓库收录游戏源码、完整运行素材和宣传资料，并提供 Vercel 静态部署配置。导入参数与发布步骤见 [Vercel 部署说明](VERCEL.md)。源码提交与网站部署是两个步骤，请以 Vercel 显示的最终部署状态和生产地址为准。

GPT 线上版通过 Sites 单独发布，与 Vercel 不会自动同步。后续修改游戏或素材后，需要分别确认两处的部署结果；不能只根据源码提交判断网站已经更新。

## 接手顺序

1. Windows 双击根目录的 `启动游戏.cmd`；也可执行 `npm start`。启动器自动打开浏览器、复用同一目录的游戏服务，并在端口占用时选择 4188～4219 中可用端口。关闭启动窗口即可停止该服务。`npm start` 仍固定使用 4188。
2. 执行 `npm test`，确认全部通过。
3. 维护题库时同时更新 `quiz.js` 与 `QUIZ_SOURCES.md`。
4. 更换美术、音频或视频时保持引用一致，检查手机端与动画首帧。
5. 发布游戏网站时使用 `dist/`；上传源码仓库时保留整个本交付目录。

未替项目选择开源许可证。确定代码及各类素材的授权范围后，再添加对应许可证和作者署名信息。

手机兼容更新：水管改用固定几何 SVG；启动解除全部图片加载依赖，轻量图按需加载并支持超时重试，存储受限仍可启动。48 项测试通过；iPhone 微信/Safari 真机复测待完成。见 [手机兼容性记录](MOBILE_COMPATIBILITY.md)。
