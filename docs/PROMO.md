# 宣传片与实机截图

## 简短介绍

一款中秋主题的像素风网页冒险游戏，融合城市探索、八种益智挑战与隐藏收集，支持电脑和手机浏览器。

## 游戏宣传片

[观看 / 下载 MP4](media/moon-chase-trailer.mp4)

- 时长：46.5 秒。
- 规格：1280 × 720，H.264 视频 / AAC 音频，30 fps 输出。
- 音乐：游戏 `main-theme.mp3`；音效来自已接入的游戏素材。
- 内容：扉页、角色对话、城市探索、路线贪吃蛇、车阵华容道、水务管网、文博问答、无人机配送、隐藏收集与故事片段。
- 画面来源：实际浏览器操作的连续截图序列，按采集时间戳剪辑。采集约 8–17 fps，输出为 30 fps；含真实操作和剧情画面。使用本地测试存档定位章节，不是完整通关录像。
- 对外传播可使用 `media/trailer-poster.jpg` 作为封面。片尾不含尚未确认的公开网址。
