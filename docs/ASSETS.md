# 素材与授权说明

本游戏以中秋短片及其分镜为故事和视觉基础，包含分镜衍生场景、角色形象、像素绘制元素、用户提供的音乐、音效与剧情视频。游戏中保留「凡拓数创 AIR 3D」标识。

## 文件范围

- `dist/assets/*.png`：游戏实际使用的场景、角色及物件图片。
- `dist/assets/audio/bgm/`：主主题及四首随机循环曲目。
- `dist/assets/audio/sfx/`：25 种交互、任务、环境与剧情音效。
- `dist/assets/video/`：两段适配网页的动画及首帧封面。
- `docs/media/`：实机截图、宣传片封面和剪辑后的介绍片。

宣传片使用游戏主主题音乐及对应操作音效。实机采集于本地浏览器，剪辑包含编辑字幕、场景切换及片尾。

## 授权状态

当前未指定开源许可证，也未把任何用户提供素材标为公共领域。公开存放不等于授予素材再使用权。代码、美术、角色、品牌、音频与视频的授权方式由各自权利方确定；如后续仅开放代码，请明确列出不在代码许可证范围内的素材目录。
